# ElitePOS for Hospitality — Website Redesign

> **Why Australian venues switch to ElitePOS**: $0 monthly POS software fees, integrated EFTPOS, and same-day bank settlements by 6:00 PM.

![ElitePOS Preview](assets/hero_pos.jpg)

## 📌 Overview
ElitePOS is an all-in-one point of sale (POS) and integrated payment platform designed specifically for Australian hospitality venues (cafes, takeaway, food trucks, full-service restaurants, pubs, and bars).

This repository contains the revamped landing page featuring:
- **Brand Identity**: Complete color and layout alignment with the official **ElitePOS** logo palette (Electric Cyan `#00C2FF`, Ocean Blue `#0066FF`, and Midnight Navy `#161144`).
- **Modern Responsive Design**: Clean, high-converting layout built with vanilla CSS, modern typography (Outfit & Plus Jakarta Sans), and glassmorphism accents.
- **Interactive Features**:
  - **Dynamic Venue Switcher**: Tailored workflow tabs for Cafes, Takeaways, Food Trucks, Restaurants, and Pubs.
  - **Live Savings Calculator**: Interactive turnover slider estimating annual cost savings vs traditional banks.
  - **Platform Ecosystem Grid**: Dual-screen countertop POS, handheld tableside terminals, kiosks, and kitchen display systems (KDS).
  - **Interactive FAQ Accordion**: Clear answers on offline mode, same-day settlement, and zero lock-in contracts.
  - **Smart Quote / Demo Form**: Streamlined lead capture with instant feedback modal.

## 🚀 Getting Started

Simply open `index.html` in any modern web browser or serve it via your local server (e.g., XAMPP, Apache, Live Server):

```bash
# Clone the repository
git clone https://github.com/giaphung2k1/Why-Australian-venues-switch-to-ElitePOS.git

# Navigate into the project folder
cd Why-Australian-venues-switch-to-ElitePOS

# Open index.html directly
start index.html
```
